# JARVIS M — JARVIS MOSHIER

A browser-based voice assistant prototype for Moshier Industries, created by Matthew Moshier.

## Features
- Futuristic JARVIS-inspired dashboard
- Browser speech recognition (Chrome/Edge support varies by device)
- Spoken responses using the browser's speech synthesis
- Command handling for greetings, time, date, help, and web searches
- Text input fallback when microphone speech recognition is unavailable
- Responsive layout for desktop and mobile

## Run it
1. Open the repository on GitHub.
2. Open `index.html`.
3. Choose **Download raw file** or download the repository ZIP.
4. Open `index.html` in a modern browser. For microphone access, use localhost or HTTPS (GitHub Pages works after deployment).
5. Press **ACTIVATE VOICE** and allow microphone access.

## Publish with GitHub Pages
1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

## Current limitations
This first version is a local browser assistant, not a full conversational AI model. It does not have access to private files, control your computer, or run background tasks. Speech recognition depends on browser support and microphone permission. Never put API keys or passwords in front-end code. A future AI integration should use a secure server-side endpoint.
